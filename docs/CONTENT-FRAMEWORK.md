# 文案框架：取材方式 × 启示落点 × 200 字预算

这份文件回答一个问题：**小毛每次到底该说什么、怎么说、说多长。**
它不是契约（契约在 [`API-CONTRACT.md`](./API-CONTRACT.md)），而是设计说明：为什么是这几个维度、哪些地方没有 100% 照原话做、还留了哪些口子。

## 1. 一条气泡的四段骨架

```
《篇名》                        出处（篇名 · 年月）
┌─ 引文 ─────────────────────┐   取材：金句 / 节选 / 小毛概括（≤70 / ≤90 字）
│ 「革命不是请客吃饭……」        │
└────────────────────────────┘
“别把立项做成表态。先拿原话回来。”   小毛的话（pua，≤40 字，第一人称）
[客户] 启示 立项前先约五个真实客户…   启示（lesson，≤100 字，必带可验证动作）
```

- **引文**必须是毛选原文（`quote`/`excerpt` 逐字命中语料），概括才允许是小毛自己的话；
- **小毛的话**是压力，不是分析：一句话点他今天该动的那个动作，且**不复述引文**（与引文有 ≥8 字公共串就整条丢弃，只留引文 + 启示）；
- **启示** = 一条硬规则 + 怎么验证。没有验证方式的启示不算启示；
- 三段合计硬上限 **200 字**，由 `fitLesson()` 保证，超了先压启示，不动引文。

## 2. 维度一：取材方式（`template`）

| 值 | 中文 | 取材 | 上限 | 用在什么时候 |
|---|---|---|---|---|
| `quote` | 原文 | 语料里的 `quote` 字段 | 70 字 | 金句最锋利时，一句话就能立住 |
| `excerpt` | 节选 | 文章正文里整句窗口（逐字，剥掉标题/列表符/资料来源） | 90 字 | 金句太短、需要上下文才懂时 |
| `summary` | 小毛概括 | 语料 `summary` 首句，或模型自己的 `gist` | 70 字 | 文章本身是论述、没有单句金句时 |

轮转 `quote → excerpt → summary`，游标 `templateCursor` 落盘。**不用 `bubbles.length`**：`maxBubbles` 封顶后长度不再变化，轮转会钉死在同一个模板上。

## 3. 维度二：启示落点（`axis`）

`客户 / 项目 / 组织 / 现金流 / 决策 / 自律`，由文章 `tags` 推导（`deriveAxis`），prompt 里再指定一次，并尽量避开上一条的落点。原来的「人事」按用户裁决改名为「组织」（招人、分工、协作、复盘问责），旧状态文件里的 `人事` 由 `LEGACY_AXES` 迁移。

**为什么不是「组织 / 项目 / 动作」三分**（这是对原话的一处有意偏离）：

- 「落点」回答的是**这件事落在哪**（客户、组织、现金流…），是名词维度；
- 「动作」回答的是**今天做什么**，是动词维度。它和落点正交——「组织落点 + 回访老员工」和「项目落点 + 回访老员工」都成立；
- 把「动作」提成第三个落点，会出现「动作类启示讲组织」这种自相矛盾的格子，而且会让另外两类失去动作约束。

所以这里的做法是：**落点 6 类（名词）+ 每条启示强制带动作与验证（动词）**。原话里「动作的」那层要求没有丢，它被提升成了所有启示的硬性成分。

## 4. 字数预算怎么花

| 段 | 上限 | 超了怎么办 |
|---|---|---|
| `cite.text` | 70（excerpt 90） | 在句读处切，切不动就整句保留 |
| `pua` | 40 | 硬截 |
| `lesson` | 100 | 先按句读截到 `200 - cite - pua` 以内，句读窗口太窄就硬截补 `…`；额度为 0 时允许为空串 |

最坏组合：cite 90 + pua 40 + lesson 70 = 200。所以「≤200」是函数级不变量，不是靠上游自觉。

## 5. 反编造的三道闸

1. `quote`/`excerpt` 必须 `isVerbatim()` 命中语料全文（比较前折叠/去掉全部空白，语料换行风格变了也不会整批退化）；
2. 不命中就降级 `summary`，`summary` 取语料 `summary` 首句，**永不回退成篇名**（篇名已经显示在卡片顶部）；
3. 模型输出解析失败 / 缺 `lesson` / headless 报错时，走本地摘录（`mode: "offline"`），UI 上明确标「离线摘录」，不冒充模型生成。

## 6. 真实样例（2026-11-01 真实 headless 调用，非构造）

**金句** · 《湖南农民运动考察报告》1927年3月 · 155 字

> 「革命不是请客吃饭，不是做文章，不是绘画绣花，不能那样雅致，那样从容不迫，文质彬彬，那样温良恭俭让。」
> “你上一次跟客户说话是哪天？今天打三个电话，只问只记，别急着推销。”
> [客户] 启示 硬规则：本周写代码前，先约三个活跃客户，各问一句「你拿它干什么活，哪步最烦」。验证：有人提到你路线图上没有的用法就改路线图；三人说法一致才算真需求。

**概括** · 《中国的红色政权为什么能够存在？》1928年10月5日 · 139 字

> 军阀混战留出缝隙，革命过的地方有群众基础，加上红军和有力的组织，红色政权就能存在发展，所以要靠根据地长期经营，不流动作战。
> “别满世界拉新了，付过费的老客才是你的地盘，今晚回访前十个。”
> [客户] 启示 每周一半获客力气花在老客身上：回访十个，只做复购和转介绍；四周内复购收入占到一成，起不来就换阵地。

**概括** · 《实践论》1937年7月 · 162 字

> 认识从实践来，先感性后理性，最终还得回到实践接受检验；判断对不对，唯一标准是社会实效，在实践中反复校正。
> “别再改首页文案了，今天挑三个真用户，让他们为这个功能掏一次钱。”
> [客户] 启示 认知必须落地两次——先把功能做成最小可用版本，再让用户真实付费。验证标准：本周内有陌生用户完成首次付费；没有，就说明你的判断还停留在感性，回实践里改。
